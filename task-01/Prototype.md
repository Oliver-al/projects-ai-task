# Prototype

当前目录存放当前任务的原型截图。

文件示例：

```text
page.png
popup.png
detail.png
empty.png
loading.png
```

## 阅读规则

请读取当前目录中的所有相关图片。

根据图片分析：

- 页面结构
- 布局
- 组件
- 文字
- 图片
- Icon
- 间距
- 状态
- 交互
- Popup
- List
- Empty
- Loading

如果图片名称能够表达页面含义，以文件名称作为辅助说明。

例如：

```text
page.png
```

表示主页面。

```text
popup.png
```

表示弹窗。

```text
empty.png
```

表示空数据状态。

```text
detail.png
```

表示详情页面。

最终实现应尽可能还原原型，同时遵循现有项目的组件和代码规范。
